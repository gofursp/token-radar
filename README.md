A token launch radar: 200 pre-token protocols ranked by implied value, with the multiple calibrated per category from the snapshot's own live-token protocols, concrete farm plans with chain-aware gas costs, and a dark dashboard with sorting, filtering and a detail view for every protocol.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input ../input/snapshot.json
```
